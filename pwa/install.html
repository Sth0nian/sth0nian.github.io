Install & launch

How the lab is running right now, and what changes once it lives on your home screen.

📲 Launch state

➕ Add to Home Screen

iOS has no install prompt (beforeinstallprompt). Installing is manual:

  • Tap ShareThe square with an arrow, in Safari's toolbar or ⋯ menu.
  • Add to Home ScreenScroll down the share sheet if it's not visible.
  • Keep "Open as Web App" onOn iOS 26 this toggle decides whether it opens standalone or as a Safari bookmark.

📐 Safe areas & viewport

The installed app uses a translucent status bar, so content sits under it unless the layout respects these insets.
